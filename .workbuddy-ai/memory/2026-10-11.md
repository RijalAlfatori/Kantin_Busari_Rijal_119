# 2026-10-11 — Kantin Bu Sari (Flutter)

## Tugas
Membangun aplikasi Flutter "Kantin Bu Sari" sesuai instruksi tugas: tiap halaman
wajib pakai >=5 widget beragam + interaktif, dan UI harus profesional.

## Yang Dikerjakan
- Melihat screenshot tugas (eksplorasi widget, UI profesional siap-guna).
- Skeleton project: model `MenuItem` + 9 sampel menu + 3 stub halaman sudah ada
  di repo, tinggal dikembangkan jadi aplikasi utuh.

## Hasil Akhir
Dibangun 6 halaman (`/`, `/menu`, `/detail`, `/cart`, `/checkout`, `/success`),
2 file state (`CartScope` InheritedNotifier + `OrderRecord`), dan widget bersama
(`RatingChip`, `MenuCard`, `CategoryPill`, `PromoBanner`, dll). Total ~11 file
Dart. Semua lulus parsing `dart format`.

## Keputusan Arsitektur
- **Tanpa dependency tambahan** — pakai `InheritedNotifier` (CartScope)
  sehingga tidak perlu `flutter pub get`.
- **Tema Material 3 + seed `#E64A19`** (deep orange khas kantin).
- **Multi-page** dengan `onGenerateRoute`, args menu dikirim via
  `ModalRoute.settings.arguments`.

## Catatan tentang Lingkungan
- Windows di mesin ini punya masalah dengan `aapt`/process spawning saat
  menjalankan `flutter doctor`/`flutter analyze`. Solusi: pakai
  `dart format` saja untuk verifikasi syntax (lulus di semua file).
- Halaman `order_page.dart` lama dihapus karena tidak dipakai lagi.
- Test lama yang ngecek counter increment diganti test smoke untuk Beranda.
- **Catatan**: `dart format` hanya verifikasi syntax, BUKAN type resolution.
  Sebelumnya sempat lupa menambahkan `import 'cart_state.dart'` di
  `order_record.dart` dan `import '../models/menu_item.dart'` di 3 halaman
  (cart, checkout, order_success) — fixed setelah user menjalankan
  `flutter run` dan dapat laporan error dari VS Code analyzer. Setelah fix,
  `dart format` lulus di 12 file.
- **Bug navigasi**: `onGenerateRoute` di `main.dart` lupa meneruskan
  `settings` ke `MaterialPageRoute`, sehingga `arguments` (MenuItem yang
  diklik) hilang dan detail selalu jatuh ke fallback `sampleMenuItems.first`
  (Nasi Goreng). Fix: tambahkan `settings: settings` di setiap
  `MaterialPageRoute`.

## File Penting
- `lib/main.dart` — entry + tema + routes + CartScope wrapper.
- `lib/state/cart_state.dart` — model keranjang + CartScope inherited.
- `lib/pages/home_page.dart` — beranda dengan search/promo/kategori/grid.
- `lib/pages/cart_page.dart` — keranjang + promo + ringkasan.
- `lib/pages/order_success_page.dart` — animasi sukses + progress dapur.
